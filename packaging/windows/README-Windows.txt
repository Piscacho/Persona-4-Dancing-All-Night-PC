Persona 4: Dancing All Night para PC
=======================================

No incluye archivos del juego. Necesitas tu propia copia de Persona 4: Dancing All Night (PS4,
CUSA12112) como carpeta: eboot.bin, sce_module y sce_sys.

Primeros pasos
1. Coloca la carpeta del juego junto a esta carpeta como juego\CUSA12112 (se detecta sola), o
   elígela en el launcher: Game -> Carpeta del juego.
2. Abre "Persona 4 Dancing All Night.exe" (el launcher). Si Windows muestra "Windows protegió
   tu PC", pulsa Más información -> Ejecutar de todas formas.
3. Pulsa PLAY.

- "Play Persona 4 Dancing All Night.exe" arranca el juego directamente con los ajustes guardados
  (útil para accesos directos o Steam).
- Dentro del juego, Insert o R3+L2 abre el menú del port.

DLC
Los DLC se usan ya extraídos de sus paquetes: cada uno es una carpeta ADDCONT<etiqueta> con
sce_sys\param.sfo y su .cpk. Cópialos en la carpeta dlc junto al launcher (directamente o dentro
de dlc\CUSA12112\), o elige otra carpeta en Game -> Carpeta de DLC. El juego monta cada DLC
cuando lo necesita.

Dónde se guarda todo
- Partidas, caché de shaders y registro: user\ junto a este archivo (consérvalo al actualizar).
- Ajustes del juego: p4d.ini junto a este archivo; ajustes del launcher en %APPDATA%\p4d-launcher.
- Registro de la última partida: user\last_run.log.

Requisitos
- Windows 10/11 de 64 bits y una tarjeta gráfica con Vulkan 1.3 (controlador actualizado).

Persona y Persona 4: Dancing All Night son marcas de ATLUS / SEGA. Este port no está afiliado a
ellas.
